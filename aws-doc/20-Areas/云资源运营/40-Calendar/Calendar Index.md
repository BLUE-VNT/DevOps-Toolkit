# 云资源到期日历

本目录由 Obsidian Daily Notes 和 Calendar 插件读取。每个日期文件对应 Calendar 中的一天。

## 规则
- 每项有 `expires` 的资源记录提前 30、15、7 天及到期当天。
- 已经早于记录创建日期的提醒节点不补建。
- 修改资源到期日期时，必须同步移动或更新对应日期笔记。
- 完成续费后，勾选旧提醒并按新日期建立下一轮提醒。
