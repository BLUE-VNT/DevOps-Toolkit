## Usage

- Adapt the domains, ports, paths, and resource settings in each example to your environment.
- Read the complete guide and back up configuration and data before running commands in production.
- Never commit passwords, tokens, private keys, or other sensitive information.
- Software versions and upstream behavior may change. Check the relevant official documentation before deployment.

## Contributing

Contributions of deployment guides, operational practices, and troubleshooting notes are welcome. When contributing:

1. Provide clear steps that have been tested.
2. Do not include real credentials or internal addresses in examples.
3. State the supported operating systems, software versions, and prerequisites.
4. Update the documentation index in every language README when adding or moving content.
